## Shivam Rawat - Resume

Static resume website for GitHub Pages. The site is built with plain HTML, CSS, and JavaScript so it can be deployed without a build step.

### Local preview

Open `index.html` directly in a browser, or serve the repository with any static file server.

### GitHub Pages

The workflow in `.github/workflows/deploy.yml` deploys the repository automatically on pushes to `main`. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
